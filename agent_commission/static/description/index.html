Odoo Agent Commission

Features

  • This modules allows you to give the Commission to Agent and also keep track of that Commission record.
  • Sale -> Customer you can configure the Agent and also set the Agent Commission Plan Based on Percentage or Fixed.


  • Inside Sale -> Order Select the Agent whom you want to give the commission and then Create the order and when you confirm that order the commission line of that agent will be added.


  • You can also able to see how much commission Agent will get inside the Agent Commission Tab and when you confirm the Sale Order the commission line of that agent are added.




  • Inside the Sale -> Agent Commission you will able to see the All the commission of the different agents.


  • Inside Sales -> Agent Commission -> Commission Payment you can able to pay the commission to the Agent manaully and also you can cancel the commission by clicking on that cancel button.




  • You can also see the invoice details and paymenty details of the Agent.




  • You can also see the This Month Orders and also see the Top 10 customers.
